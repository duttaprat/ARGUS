# ARGUS examples

No executable examples are included yet because this checkout does not contain ARGUS source or a verified command-line interface.

Future examples should be small, synthetic or approved for redistribution, and reproducible. Each example should document:

- Its purpose and the component being demonstrated.
- Required code revision, resource versions, genome assembly, and coordinate convention.
- The verified command or entry point and required local configuration.
- Expected evidence facts, verification outcome, and stopping or abstention behavior.
- Whether the optional planner is used and any resulting reproducibility limits.

Use relative paths and placeholders for local dependencies. Keep credentials, weights, databases, bulk inputs, large outputs, and user-specific server paths out of examples. `examples/local/` is ignored for local trials.

Any AlphaGenome Atlas example must be labeled as a standalone computational cross-reference, separate from the investigation loop. Do not present an illustrative output as a measured ARGUS result.
