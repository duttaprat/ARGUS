# ARGUS presentation assets

These assets illustrate the documented ARGUS investigation behavior. They are presentation materials, not new experimental results or a recording of a live run.

| Asset | Purpose |
| --- | --- |
| [ARGUS symbol](argus-symbol.svg) | Teal orbital A mark, adapted from the approved visual concept |
| [Animated investigation](argus-demo.gif) | Compact 22-second looping illustration for the repository README |
| [Still image](argus-demo-poster.png) | Non-animated view of the FOXA1 illustration |
| [Interactive version](argus-demo.html) | Download and open locally for pause/play controls |
| Status, verifier, and evaluation badges | Local static labels describing the current project scope; not CI or benchmark measurements |

The GIF shows two illustrated cases using precomputed DVR probabilities: FOXA1 rescue from admissible direct experimental evidence, and KLF6 abstention because motif evidence opposes DVR while regulatory context remains non-resolving. AlphaGenome Atlas is shown separately, outside the loop.

The animation does not demonstrate a complete natural-language-to-DVR-to-investigation workflow. Its timing is editorial pacing, not measured execution time. The reporter cannot override deterministic classifications.

The existing primary scientific architecture figure remains in [the figures directory](../figures/ARGUS_architecture.png). The README header and demo complement that figure.

The badges are checked-in SVG assets, with no dependency on third-party badge services. They do not assert a license, a published paper, released weights, passing CI, or predictive accuracy.

The interactive version is a portable export of the approved visual concept. Its core diagram runs locally; the export wrapper includes optional shared interface helpers loaded from a CDN. It requires no credentials or ARGUS backend. GitHub displays the GIF and SVG assets in the README; download the HTML to use its interactive controls locally.
